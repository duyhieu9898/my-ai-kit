## 🛠️ Instructions / Procedures

When tasked with performing SEO/GEO audits, implementing schemas, or auditing page core web vitals, strictly follow this step-by-step procedure:

### Step 1: Detect Technical Compliance
1. Review XML sitemaps, robots.txt, HTTPS access, and canonical links.
2. Confirm mobile responsiveness structures.

### Step 2: Validate Content Hierarchies
1. Check title lengths (50-60 chars) and meta descriptions (150-160 chars).
2. Enforce exactly one H1 per page and sequential heading nesting (H2-H6).

### Step 3: Implement Schema Markups
1. Structure JSON-LD schema definitions mapping author expertise credentials and article entities.
2. Document E-E-A-T references clearly.

### Step 4: Audit Core Web Vitals
1. Run local page metrics checking LCP (<2.5s), INP (<200ms), and CLS (<0.1) benchmarks.
2. Flag potential resource-heavy assets.

### Step 5: Verify GEO & Audit checklist
1. Organize content structure using clear definitions, FAQ blocks, comparison tables, and statistical sources.
2. Confirm compliance against the **Quality Audit Checklist** before completing.

## ❌ Anti-Patterns

- Optimizing for AI citation while leaving technical SEO basics broken.
- Publishing generic AI-written content without original data, expert review, or visible sources.
- Adding JSON-LD schema that contradicts visible page content.
- Treating Core Web Vitals as optional when page experience is a ranking and citation trust signal.

## ✅ Quality Audit Checklist

Before concluding an SEO audit, Schema markup implementation, or Core Web Vitals profiling task, verify compliance with the following:

- [ ] **Technical sitemaps set**: Verified valid sitemaps, correct robots.txt configurations, canonical tags, and HTTPS enablement.
- [ ] **Content Hierarchies Correct**: Verified exactly one `<h1>` tag per page and proper hierarchical heading nesting (`<h2>` to `<h6>`).
- [ ] **Metadata Limits Met**: Confirmed page titles are between 50-60 characters and meta descriptions are under 150-160 characters.
- [ ] **E-E-A-T credentials featured**: Mapped author biographies, experience stories, and expert quotes to support citation trust.
- [ ] **Core Web Vitals Checked**: Assured LCP remains under 2.5s, INP under 200ms, and CLS under 0.1.
- [ ] **GEO Citations structured**: Structured content with clear comparison tables, statistical sources, and expert quotes to support AI search retrieval.
